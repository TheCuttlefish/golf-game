
# Cuttlefish Tools

**Version 1.0**

Blender-inspired transform and workflow tools for the Unity Editor.

## Getting Started

1. Open Unity and select the Scene View.
2. Find Cuttlefish Tools in the Overlays menu.
3. Drag the toolbar into the Scene View or dock it in Unity's overlay bar.
4. Select an object and start transforming!

## Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| G | Move |
| R | Rotate |
| S | Scale |
| X / Y / Z | Constrain to an axis |
| Shift + X/Y/Z | Exclude an axis while scaling |
| R then R | Trackball rotation |
| Shift + D | Duplicate and move |
| Ctrl | Snapping during transforms |
| Shift | Precision movement |
| Number keys | Numeric transform input |
| Enter | Confirm transform |
| Esc | Cancel transform |
| Shift + A | Open Add Menu |
| Space | Open Action Menu |

## Add Menu

Press **Shift + A** to open the object creation menu.

Search for objects, browse categories, and select an item to add it to your scene.

## Action Menu

Press **Space** to open the Action Menu.

Access pivot, orientation, alignment, and other transform-related controls.

## Unity Overlay

Cuttlefish Tools uses Unity's native Scene View Overlay system.

- **Floating:** Displays the full toolbar.
- **Docked:** Displays the compact Cuttlefish icon.
- **Tools > Cuttlefish Mode:** Switches between floating and docked modes.

## Notes

Cuttlefish Tools is an Editor extension and does not add runtime components to your game.
